一、术语表

下表中的说明为官方文档原文引用或紧贴原文的转述；带 等宽字体 的是真实参数名或节点名。

术语官方说明（引用/转述自官方文档）来源
节点（Node）ComfyUI 中节点是我们执行任务的单元：无论是 Comfy Core 还是自定义节点，每个节点都是独立模块，节点之间通过连线连接。官方页面（需联网）
连线（Link）节点之间绘制的线条或曲线称为连线，把数据从一个节点的输出传输到另一个节点的输入，从而定义工作流的流程。官方页面（需联网）
端口颜色 / 数据类型每种数据类型都有独特的颜色，节点的输入输出端口与连线都遵循该配色；只能连接相同颜色的端口，以保证类型安全。常见类型有 IMAGE、LATENT、MASK、MODEL、CLIP、VAE、CONDITIONING。官方页面（需联网）
潜空间（Latent / LATENT）扩散模型不是在像素上直接工作，而是在压缩后的潜空间里运算。EmptyLatentImage 用于生成具有指定尺寸和批次大小的空白潜空间表示；VAEEncode 把图像编码进潜空间。官方页面（需联网）
Checkpoint指真正参与运算的权重文件（例如 checkpoint、VAE、LoRA、ControlNet、放大模型等），放在 ComfyUI/models/ 对应子文件夹，再在加载器节点里选中。CheckpointLoaderSimple 会把 checkpoint 拆成 MODEL（主模型）、CLIP（文本编码器）、VAE（图像编解码器）三个输出。官方页面（需联网）
CLIP文本编码器：用 CLIP 模型把提示词编码为嵌入（embedding），用来引导扩散模型。官方页面（需联网）
VAE图像编码器/解码器：VAEDecode 把 LATENT 解码成图像，VAEEncode 把图像编码成 LATENT。官方页面（需联网）
CONDITIONINGCLIPTextEncode 的输出类型，包含用于引导扩散模型的嵌入文本。官方页面（需联网）
种子 seed用于生成随机噪声；使用相同的“种子”将生成相同的图像。默认 0，范围 0 ~ 18446744073709551615。官方页面（需联网）
步数 steps去噪过程中使用的步数，步数越多结果越精确。默认 20，范围 1 ~ 10000。官方页面（需联网）
cfg控制生成图像与输入条件的匹配程度，官方建议值 6-8，默认 8.0。官方页面（需联网）
采样器 sampler_name选择用于去噪的采样器，影响生成速度和风格。数据集可选 44 项。官方页面（需联网）
调度器 scheduler控制噪声的移除方式，影响生成过程。数据集可选 9 项。官方页面（需联网）
降噪 denoise决定噪声移除比例，默认 1.0，范围 0.0 ~ 1.0。图生图必须小于 1：越小与参考图差异越小；等于 1 时潜空间图变为完全随机的噪声。官方页面（需联网）
LoRA一种用于微调大型生成模型的高效技术：在预训练模型上引入可训练的低秩矩阵，以较低计算成本实现特定任务的优化；使用时可把 LoRA 当作“滤镜”。官方页面（需联网）
ControlNet通过引入多模态输入条件（边缘检测图、深度图、姿势关键点等）显著提升图像生成的可控性和细节还原能力。官方页面（需联网）
遮罩（Mask）指示输入图像中需要修复区域的遮罩；VAEEncodeForInpaint 会用它修改图像，让 VAE 聚焦相关区域。扩展遮罩 grow_mask_by 越大，修复影响的区域越大。官方页面（需联网）
放大模型（UPSCALE_MODEL）UpscaleModelLoader 加载放大模型，ImageUpscaleWithModel 用它把图像放大；模型放在 ComfyUI/models/upscale_models。官方页面（需联网）
工作流模板（Templates）工作流模板是 ComfyUI 中原生支持的模型工作流及自定义节点提供的模型工作流的浏览窗口，可由 侧边栏 Templates 或 工作流 → 浏览工作流模板 打开。官方页面（需联网）
自定义节点由第三方作者开发的扩展节点。工作流里出现“丢失（Missing）”状态时，若属于自定义节点，说明本地尚未安装对应扩展，可用 ComfyUI Manager 查找并安装。官方页面（需联网）
节点状态常见状态：正常、运行（正在执行）、错误（输入有问题，红色标识出错输入）、丢失（原生节点丢失通常是版本旧；自定义节点丢失通常是未安装）。官方页面（需联网）
节点数据集ComfyUI 后端提供的节点信息接口。本站的“已收录”数据来自用户公开节点数据集文件 节点数据集快照（1459 个节点，含真实键名、输入参数默认值、category 与 python_module）。本地 节点数据集快照（本项目来源 S6，见 SPEC 第 7 节）

二、常见问题

Q1. 运行工作流时某个节点变成红色 / 报错怎么办？

那是节点的错误（Error）状态：官方文档说明，运行工作流后如果对应节点的输入存在问题就会显示这个状态，并用红色标识出错的输入节点，你需要解决对应出错的输入才能让工作流正常运行。先顺着红色连线检查上游输出类型是否匹配。

依据：官方《节点》（需联网）

Q2. 拖入工作流后出现“丢失（Missing）”的节点，怎么办？

官方文档给出两种可能：① Comfy Core 原生节点丢失——通常是 ComfyUI 版本较旧（工作流用了更新的节点），更新 ComfyUI 即可；② 自定义节点丢失——工作流用了第三方作者开发的扩展而本地尚未安装，可用 ComfyUI Manager 查找安装，或参考《如何安装自定义节点》。

依据：官方《节点》（需联网）

Q3. 为什么有些节点在官方文档里（或在本站）查不到？

因为官方内置节点文档只覆盖 内置节点。公开节点数据集 还安装了自定义节点包——本站统计到 11 个包、635 个节点（如 ComfyUI-Impact-Pack 197 个、ComfyUI-WanVideoWrapper 147 个、ComfyUI-LTXVideo 78 个、comfyui_controlnet_aux 64 个）。它们的用途请查阅各自仓库的 README；本站只在节点百科里按 节点数据集 如实展示它们的真实参数，不对其功能做推测性描述。

依据：节点数据集（S6）+ 官方《节点》（需联网）

Q4. 图生图 / 局部重绘生成出来几乎没变化，或者完全变了？

看 denoise：图生图必须小于 1。官方教程说明——denoise 越小，生成图像与参考图差异越小；越大差异越大；denoise 为 1 时潜空间图会变成完全随机的噪声，参考图特征全部丢失；只有 denoise 为 0 时才完全不执行采样步。

依据：官方图生图教程（需联网）

Q5. 为什么把 denoise 调低以后，生成反而没有变快？

官方教程的原文说明：调低 denoise 不会减少实际执行的采样步数。ComfyUI 会按 steps / denoise（向下取整）构建调度表，再保留最后 steps + 1 个 sigma。若想在保持步长密度的情况下只采样部分噪声区间，把 steps 设为“运行步数 × denoise”。

依据：官方图生图教程（需联网）

Q6. 提示词怎么写才有效？

官方文生图教程的原则：尽量用英文；用英文逗号分隔；尽量用短语而不是长句；描述更具体；用 (golden hour:1.2) 这类写法提升关键词权重。CLIPTextEncode 文档补充：普通括号 (word) 应用默认权重 1.1；用 \\(word\\) 表示字面括号；{a|b|c} 是动态提示词；embedding:模型名 可引用嵌入模型。

依据：官方文生图教程 + CLIPTextEncode 文档（需联网）

Q7. LoRA 加载了但没什么效果，怎么调？多个 LoRA 能一起用吗？

LoraLoader 文档：模型强度（strength_model）与 CLIP强度（strength_clip）取值范围 -100.0 到 100.0，日常图像生成通常在 0~1 之间使用，数值越高调整效果越明显。想叠加多个 LoRA，把多个 LoraLoader 串联起来即可（官方另有《应用多个 LoRA 示例》）。另外 LoRA 文件要放在 ComfyUI\models\loras（节点会自动检测该目录，含子文件夹）。

依据：LoraLoader 官方中文文档（需联网）

Q8. ControlNet 要配什么图？为什么找不到预处理器节点？

官方教程：不同类型的 ControlNet 需要不同类型的参考图（线稿、深度图、姿态图等）；并且说明 Comfy Core 节点中不包含所有类型的预处理器，实际使用常需要借助自定义节点，例如 ComfyUI ControlNet aux、ComfyUI-Advanced-ControlNet。已收录 comfyui_controlnet_aux（64 个节点，如 CannyEdgePreprocessor、OpenposePreprocessor、DepthAnythingV2Preprocessor）。

依据：官方 ControlNet 教程 + 节点数据集（需联网）

Q9. 模型文件应该放在哪个目录？

官方《模型》：放到 ComfyUI/models/ 下与类型对应的子文件夹（如 checkpoints、loras、vae），再在加载器节点（名称里通常带 Load）的下拉菜单里选择。其它教程补充：放大模型放 models/upscale_models；ControlNet 模型放 models/controlnet。放好后按 R 刷新节点列表。

依据：官方《模型》+ 放大/ControlNet/Stable Audio 教程（需联网）

Q10. 生成的音频、视频保存到哪了？

ACE-Step 教程：音频会被保存至 ComfyUI/output/audio，由 Save Audio 节点决定子目录名。视频则由 CreateVideo/SaveVideo 决定，SaveVideo 的 filename_prefix 默认是 video/ComfyUI。

依据：ACE-Step 教程 + SaveVideo 文档（需联网）

Q11. 找不到教程里说的官方模板，或者提示节点缺失？

官方教程 Tip：模板可以通过 工作流 → 浏览模板 加载；如果找不到，可能是 ComfyUI 没有更新，建议更新到最新版（每夜版）。节点缺失的另一个原因是“启动时有些节点导入失败”。模板本身由独立依赖 comfyui-workflow-templates 管理，更新 ComfyUI 后如果看不到新模板，可能是该依赖没更新。

依据：Wan2.2 教程 + 工作流模板页（需联网）

Q12. 官方文档里的中文说明可以直接相信吗？

可以当作主要参考，但要知道官方节点文档由 AI 生成：每篇节点文档页脚都写着“本文档由 AI 生成”。本站因此对每一条内容都标注了来源，并把“节点数据集 的真实参数名与默认值”作为机器可核对的事实；若文档与你的界面不一致，以官方页面与本地环境为准。

依据：官方文档页脚（见 vendor/docs/nodes/zh/*.md）（需联网）

Q13. 这个网站为什么断网也能用？

本站是纯静态页面：所有数据以 assets/nodes-data.js 这类本地 JS 文件提供，不使用 fetch/XHR、不引用 CDN、字体或远程图片，因此双击 index.html（file:// 协议）即可浏览。页面里的站外来源链接需要联网才能打开，已逐条标注“需联网”。

依据：本项目 SPEC 第 1、5 节（需联网）
