ComfyUI 节点基础概念

ComfyUI 是节点式（可视化编程）的生成式 AI 工具：把节点连起来组成工作流，数据沿着连线流动。理解这四件事就够了。

1. 节点（Node）

官方定义：「节点是 ComfyUI 的基本构建块：通过连线连接的独立 Comfy Core 或自定义模块，用来组装复杂工作流。」

每个节点是一个独立模块，各管一段功能：加载模型、编码提示词、采样、保存文件。节点几乎总至少有一个输入或输出。

来源：官方文档《节点》 需联网

2. 端口与连线（Port / Link）

节点之间画的线叫连线：把上一个节点的输出接到下一个节点的输入，定义了工作流的数据流。

官方强调：只能连接相同颜色的端口（同一种数据类型）。连不上，通常就是数据类型不匹配。

来源：官方文档《连线》 需联网

3. 属性 / 参数（Properties）

节点上的属性（也叫参数）决定节点怎么工作，例如 KSampler 的步数、CFG、采样器名称。

大多数属性可以在节点上手动填，也可以改由别的节点驱动（接到输入端口）。ComfyUI 环境是强类型的，不同数据类型不能混用。

来源：官方文档《属性》 需联网

4. 工作流（Workflow）

官方定义：「工作流是一组步骤，告诉 ComfyUI 如何创建内容。」可以当成食谱：食谱＝工作流，每条指令＝节点，食材＝提示词、图像和模型。

工作流能存成 JSON 独立分享；保存节点输出时 ComfyUI 也会把工作流嵌进文件里，把图片拖回画布即可还原。

来源：官方文档《工作流》 需联网

颜色对应关系来自官方《连线》的颜色编码表；「类型名」是你在节点端口与数据集 节点数据集 里实际看到的标识符。

新手入门路径

五步从零跑到出图，每步都标注了官方来源。

  1. 1

    先把 ComfyUI 跑起来

    本地安装（便携版 / 桌面版 / 手动安装）后打开界面；不想本地安装，也可以先用官方云服务。

    来源：官方《开始 ComfyUI 的 AI 绘图之旅》 需联网

  2. 2

    打开一个模板工作流

    菜单 工作流 → 浏览工作流模板，选一个文生图模板；模板会提示你需要下载哪些模型。

    来源：官方《工作流》 需联网

  3. 3

    认清最小可运行的链路

    官方举的四步是：加载模型 → 编码提示词 → 采样 → 保存图像；完整最小链路还包含空潜空间画布与 VAE 解码。点开直达本站词条：

    • CheckpointLoaderSimple加载 checkpoint，输出 MODEL / CLIP / VAE
    • CLIPTextEncode正向 / 负向提示词编码
    • EmptyLatentImage生成空白潜空间画布（宽高在这里设）
    • KSampler按模型与条件对潜空间去噪
    • VAEDecode潜空间解码成像素图像
    • SaveImage保存图像（并写入工作流元数据）

    来源：官方《工作流》；节点名与端口取自数据集 节点数据集 导出 需联网

  4. 4

    备好模型文件

    模型不随安装包附带：把下载的权重放进 ComfyUI/models/ 下对应子目录（如 checkpoints、loras、vae），再在加载器节点的下拉菜单里选它。

    来源：官方《模型》 需联网

  5. 5

    运行 → 排错

    工作流跑不动通常是缺模型、缺自定义节点或 Python 依赖。缺节点可对照 节点百科 搜索确认它属于哪个包，再看 术语与排错。

    来源：官方《依赖关系》 需联网
